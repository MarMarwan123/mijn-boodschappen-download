# Mijn Boodschappen voor Android

[Download de nieuwste APK](https://github.com/MarMarwan123/mijn-boodschappen-download/releases/latest/download/Mijn-Boodschappen.apk)

Open het gedownloade APK-bestand op je Android-telefoon en bevestig de installatie. Als je een uitnodiging voor een gedeelde lijst hebt ontvangen, open je dezelfde uitnodigingslink na de installatie opnieuw.

De app controleert op nieuwe versies wanneer je haar opent. Zodra er een update klaarstaat, kun je die in de app downloaden en installeren.

[Versies bekijken](https://github.com/MarMarwan123/mijn-boodschappen-download/releases)
